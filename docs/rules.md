# Lint rules

Generated by `npm run docs` from `src/lint/rules.ts`: every rule `staleproof lint` knows, its default severity, where it looks, and what a finding says. Change a severity or turn a rule off in `.staleproof.toml` (`[rules] "rule-id" = "off" | "info" | "warning" | "error"`); silence one line with `<!-- staleproof: ignore rule-id -->`. Beta rules report at info and never fail a check until `[rules]` opts them in ([False positives](false-positives.md#how-maturity-works)). No rule is free of false positives: the evidence under each rule says what was checked and what was wrong. See [Lint](lint.md).

## path-missing

A code span names a file or directory of the repository that does not exist. Readers and coding agents open the path, find nothing, and guess. Moved and deleted files are the most common drift in agent instructions.

- Default severity: **info** (**error** when opted in)
- Maturity: **beta**: reported at **info**, lower confidence, until `[rules] "path-missing" = "error"` opts it in. Hand-checked on 8 repositories (the 0.4 precision runs: httpx, flask, TypeScript, python-sdk, codex, pydantic-ai, vercel/ai, this one): every final finding true (codex 3, pydantic-ai 5), 20 verified fixes on pydantic-ai; true again on pmndrs/valtio (2, a deleted Next.js route its README names). First-run false positives (other projects' paths in docs, skill-relative paths) closed by guards: a docs page needs git-history evidence. Drift Hall (Oct 18: 63 repositories Staleproof was never tuned on, every warning and error hand-checked, staleproof.dev/#/drift): 7 true, 32 false; the 0.8.0 guards leave 7 true, 0 false: placeholder segments (`../NNNN/results.md`, `your_provider.md`), pages of history (changelogs, plans, proposals, decision records, issue drafts) and templates (`templates/AGENTS.md`), check, label and branch names (`license/cla`), paths the sentence says are gone, where another tool looks (`.github/skills/`), sibling folders outside the repository, module paths without their extension, paths relative to a package or skill the paragraph names or to the code an agent file governs (`../fixtures`, a Cursor rule's `globs`), a path like its siblings (`test_provider/evals`). Fixture `path-missing-zod-placeholder`. But the held-out check (Oct 18: 18 popular repositories in none of the hall or the earlier runs, linted only after those guards were written, every warning and error hand-checked) found 0 true, 12 false: mostly records of a removal without a PR reference, another repository's paths, and plans. Beta in 0.8.0 under the 80% rule.
- Checks: agent files, READMEs, docs

Reported on:

```text
Config lives in `src/settings/defaults.ts`.
```

Message: `src/settings/defaults.ts` does not exist in the repository.

## line-out-of-range

A `path:line` reference points past the end of the file. Line references rot as files shrink; the reader lands on the wrong code.

- Default severity: **info** (**warning** when opted in)
- Maturity: **beta**: reported at **info**, lower confidence, until `[rules] "line-out-of-range" = "warning"` opts it in. A line count on a file path-missing resolved in this repository, so it shares that rule's guards. No finding, true or false, on the 8 the 0.4 precision runs repositories or the 14 of the Oct 18 sweep (zustand, zod, jotai, typer, ky, click, starlette, rich, black, sqlmodel, execa, valtio, hono, vite). The held-out check (Oct 18: 18 fresh repositories, hand-checked) found 0 true, 1 false and 2 unclear, and no true finding on any of the 81 repositories checked: beta in 0.8.0 under the 80% rule.
- Checks: agent files, READMEs, docs

Reported on:

```text
See `src/cli.ts:812`.
```

Message: `src/cli.ts` has 523 lines; line 812 does not exist.

## link-broken

A relative link points to a file that does not exist. Broken links in docs and agent files send readers (and agents following them) nowhere.

- Default severity: **error**
- Maturity: **stable**. True findings on TypeScript (1), vercel/ai (25, 31 verified fixes), colinhacks/zod (3) and pmndrs/jotai (3, a renamed docs folder). First-run false positives (mkdocstrings-generated pages, translations, docs-root links) closed by guards. Drift Hall (Oct 18: 63 repositories Staleproof was never tuned on, every warning and error hand-checked, staleproof.dev/#/drift): 586 true, 418 false (58%), almost all docs-site routing; the 0.8.0 guards leave 586 true, 9 false (98%), none of the true ones lost: MkDocs configs split over files (textual's raw-HTML hrefs) and TanStack's `docs/*/config.json` count as docs sites, pages served without their order prefix (svelte, gradio), `entry.server.tsx.md` pages, doc-builder `_redirects.yml` (the English one for translations), Storybook `staticDirs`, fragments a site includes (snippets, `docs_src/` annotations), Vue bindings (`:href`), placeholder targets, templates, sample data, prefixes a generated page says it omits. A host written without its scheme (textual's `github.com/textualize/rich`) is still reported on a docs site. Left: svelte's compiler messages (7), react-router 2. Fixtures `link-broken-vite-vue-bound-href`, `link-broken-sqlmodel-included-fragment`.
- Checks: agent files, READMEs, docs

Reported on:

```text
Read the [deploy guide](docs/deploy.md).
```

Message: The link target `docs/deploy.md` does not exist.

## anchor-missing

A link to `#anchor` matches no heading in the target page. Renamed headings silently break deep links: the page opens at the top.

- Default severity: **info** (**warning** when opted in)
- Maturity: **beta**: reported at **info**, lower confidence, until `[rules] "anchor-missing" = "warning"` opts it in. True findings on httpx (6) and zod (5), but more false ones on fresh repositories (Oct 18 sweep): pmndrs/zustand 8 of 8 (its docs site keeps punctuation in heading ids, and `<#a-(b)-c>` was cut at the first `)`; 0.7.0 reads the whole destination and reports a heading found under another slugger at info, with no fix), colinhacks/zod about 12 of 18 (headings after a code block that closes its HTML comment on the fence line, ``` -->, and links inside MDX comments: both fixed in 0.8.0). Drift Hall (Oct 18: 63 repositories Staleproof was never tuned on, every warning and error hand-checked, staleproof.dev/#/drift): 148 true, 249 false (37%), most from docs-site sluggers (MkDocs attr_list and toc, VitePress, Mintlify, TanStack, hf doc-builder). Fixtures `anchor-missing-zustand-*`, `anchor-missing-zod-*`. After the 0.8.0 guards, on the 61 hall repositories other than crewAI and haystack, above info (a heading under another slugger is an info note with no fix): 134 true, 23 false (85%), from 109 false: MkDocs attr_list ids (`{ #id }`, fastapi 35, marimo 12), hf doc-builder `[[id]]` ids and slugs (`HF_TOKEN` → `hftoken`, huggingface_hub 30), generated API anchors (`[[autodoc]]`, `:::`, smolagents 10). Still beta for 0.8.0 (decided before this measurement; crewAI's 207 anchors are not judged): a candidate for stable.
- Checks: agent files, READMEs, docs

Reported on:

```text
See [options](cli.md#global-flags).
```

Message: `cli.md` has no heading `#global-flags`.

## command-missing

A documented command (`npm run x`, `make x`, `just x`, `uv run x`, ...) is not defined by the repository. Setup and contributing steps are run verbatim, by people and by agents; a renamed script fails the first step.

- Default severity: **error**
- Maturity: **stable**. the 0.5 precision runs: 22 repositories, 1 300+ invocations judged, 5 findings, all true (codex 1, cline 4); 17 verified fixes on simulated renames; nothing false on the 14 repositories of the Oct 18 sweep. Every first-run false positive (go-task's users' tasks, another project's layout after `cd`) closed by a guard. Drift Hall (Oct 18: 63 repositories Staleproof was never tuned on, every warning and error hand-checked, staleproof.dev/#/drift): 13 true, 7 false (65%); the 0.8.0 guards (`make format/lint/typecheck` shorthand for existing targets, a sentence that says the command is not there, blocks introduced as output) leave 13 true, 2 false (87%): nuxt's and express's scripts of the reader's generated app.
- Checks: agent files, READMEs, docs

Reported on:

```text
Run `npm run lint:docs` before pushing.
```

Message: `lint:docs` is not a script in package.json.

## cli-command-unknown

The repository's own CLI is shown with a subcommand it does not have. CLI docs drift with every rename; users copy the command and get a usage error.

- Default severity: **error**
- Maturity: **stable**. the 0.5 precision runs: the CLI models of 13 repositories (click, typer, argparse, commander) judged against 1 300+ invocations with no false positive left (none either on the Oct 18 sweep: typer, click, black, rich); first-run ones (log lines like `staleproof mcp:`, an unrelated parser reached through `main()`) closed by guards. Drift Hall (Oct 18: 63 repositories Staleproof was never tuned on, every warning and error hand-checked, staleproof.dev/#/drift): 7 true, 6 false (54%), all crewAI's `uv tool list` output (`crewai v0.102.0`) in a shell block; 0.8.0 reads a block introduced as output, or holding listing rows, as output: 7 true, 0 false.
- Checks: agent files, READMEs, docs

Reported on:

```text
`mytool sync --all`
```

Message: `mytool` has no command `sync` (commands: pull, push).

## cli-flag-unknown

The repository's own CLI is shown with an option it does not accept. Removed and renamed flags are a classic source of copy-paste failures.

- Default severity: **info** (**error** when opted in)
- Maturity: **beta**: reported at **info**, lower confidence, until `[rules] "cli-flag-unknown" = "error"` opts it in. the 0.5 precision runs: 22 repositories and 1 300+ invocations, leaf options judged (llm, datasette, sqlite-utils, hatch), no false positive left after the guards. But the Drift Hall (Oct 18: 63 repositories Staleproof was never tuned on, every warning and error hand-checked, staleproof.dev/#/drift) found 6 true, 245 false (2%): commander subcommands defined in other modules and mounted with `addCommand` (shadcn-ui 110), a launcher that forwards argv to sub-CLIs (modelcontextprotocol/inspector 134), two CLIs with one name (mem0). Beta until the CLI model follows them (src/lint/facts-cli.ts).
- Checks: agent files, READMEs, docs

Reported on:

```text
`mytool push --force-all`
```

Message: `mytool push` has no option `--force-all`.

## env-unused

A documented environment variable is never read by the code. Users set it and nothing changes; usually the variable was renamed.

- Default severity: **warning**
- Maturity: **stable**. Every application in the 0.5 precision runs had first-run false positives, each closed by a per-ecosystem guard (pydantic-ai 11, vercel/ai 67, uvicorn's FORWARDED_ALLOW_IPS, Blaxel's BL_REGION). Drift Hall (Oct 18: 63 repositories Staleproof was never tuned on, every warning and error hand-checked, staleproof.dev/#/drift): 67 true, 11 false (86%), so stable again (C had made it beta in 0.8 on one repository): pmndrs/zustand's `MDX` and `HOME_REDIRECT` in CONTRIBUTING.md, read by the pmndrs/docs checkout the step tells you to make, are guarded (a variable set in another repository's checkout is not judged), fixture `env-unused-zustand-other-checkout`; left: variables of another product the docs configure (LiteLLM's in adk-python, TAVILY_API_KEY in langgraph).
- Checks: agent files, READMEs, docs, env files

Reported on:

```text
Set `DATABASE_URI` to your database.
```

Message: `DATABASE_URI` is documented but no code reads it.

## env-undocumented

The code reads an environment variable the repository's env file does not list. New settings that never reach `.env.example` are found by reading the source.

- Default severity: **info**
- Maturity: **stable**. Already info. the 0.5 precision runs: every info on flask, python-sdk, codex, openai-agents-js, OpenHands and vercel/chatbot checked, samples on vercel/ai, browser-use and cline: all true; test-runner variables (PLAYWRIGHT) and test configs closed by guards.
- Checks: env files

Reported on:

```text
process.env.REDIS_TLS
```

Message: `REDIS_TLS` is read in src/db.ts but not listed in .env.example.

## symbol-missing

A code span names a member of a repository class or module that does not exist. Prose that names `Client.query_v2` after it was renamed teaches readers and agents an API that is gone.

- Default severity: **info** (**error** when opted in)
- Maturity: **beta**: reported at **info**, lower confidence, until `[rules] "symbol-missing" = "error"` opts it in. No true finding on any real repository before the Drift Hall: all 36 of its first-run findings (python-sdk 28, pydantic-ai 7, flask 1) were false and became guards (a package name bound as a variable, members need a call, history per sentence). Drift Hall (Oct 18: 63 repositories Staleproof was never tuned on, every warning and error hand-checked, staleproof.dev/#/drift): 7 true, 28 false (20%), the false ones in release notes and proposals (scrapy's `docs/news.rst`, `sep/`).
- Checks: agent files, READMEs, docs

Reported on:

```text
Call `Client.query_v2()`.
```

Message: `Client` has no member `query_v2`.

## docstring-param-unknown

A docstring documents a parameter the function's signature does not have. Docstrings feed IDE hovers, API reference sites and agents; a renamed parameter makes them wrong everywhere.

- Default severity: **error**
- Maturity: **stable**. 27 true errors, each checked: vercel/ai 2, OpenHands 1, cline 13, zod 1 (`ZodDiscriminatedUnion.create` `@param types`), Textualize/rich 9, vitejs/vite 1; none false on the Oct 18 sweep. First-run false positives (a `# noqa` comment hiding a parameter, `_x` for `x`, inline object fields, JSDoc in prose) closed by guards. Drift Hall (Oct 18: 63 repositories Staleproof was never tuned on, every warning and error hand-checked, staleproof.dev/#/drift): 172 true, 18 false (91%): type-first entries (`int (size)`), section headers indented inside `Args:`, nameless JSDoc `@param {object} A server address`, sample docstrings in a code block.
- Checks: docstrings

Reported on:

```text
Args:
    timeout_ms: ...
```

Message: `connect` has no parameter `timeout_ms` (parameters: host, port, timeout).

## docstring-param-undocumented

A docstring documents most of the parameters but leaves one out. Partly documented signatures usually mean a parameter was added without its docs.

- Default severity: **info**
- Maturity: **stable**. Already info. Hand-checked on flask (4), python-sdk (13), codex, cline, openai-agents-js, pallets/click (11): all true once docstrings that document a minority of parameters on purpose were left out (at least half must be documented).
- Checks: docstrings

Reported on:

```text
def connect(host, port, tls): """Args: host, port"""
```

Message: `connect` documents host, port but not `tls`.

## example-unknown-keyword

A docs code example passes a keyword argument the function does not accept. The example fails when copied: a TypeError in Python, a type or compile error in TypeScript and Go.

- Default severity: **info** (**error** when opted in)
- Maturity: **beta**: reported at **info**, lower confidence, until `[rules] "example-unknown-keyword" = "error"` opts it in. Static example checks since 0.3: every finding on the 8 original repositories real drift; the 0.5 language runs regression runs unchanged. But the Drift Hall (Oct 18: 63 repositories Staleproof was never tuned on, every warning and error hand-checked, staleproof.dev/#/drift) found 13 true, 876 false (1%): the first `@overload` taken without overload resolution made every `instructor.from_provider(...)` client the wrong class (567-labs/instructor 851), receivers typed wrong (`with X() as y`, `await`, containers). After the 0.8.0 guards, on the 61 hall repositories other than crewAI and haystack: 9 true, 882 false before, 9 true, 30 false after (23%): an overloaded call's result is known only when every overload agrees, and a name on a docs page is its latest binding above the line. Left: history pages (fastmcp's `docs/v2`, mem0), receivers of `with` and `await`.
- Checks: code examples

Reported on:

```text
Client(hostname="db.local")
```

Message: `Client` has no parameter `hostname`.

## example-too-many-arguments

A docs code example passes more positional arguments than the function takes. The example fails when copied: a TypeError in Python, a type or compile error in TypeScript and Go.

- Default severity: **info** (**error** when opted in)
- Maturity: **beta**: reported at **info**, lower confidence, until `[rules] "example-too-many-arguments" = "error"` opts it in. True: vercel/ai 4 (constructors that dropped `settings`). zod's 14 first-run false positives (API listings, versioned docs) closed by guards. Drift Hall: 11 true, 21 false (34%). After the 0.8.0 guards, on the 61 hall repositories other than crewAI and haystack: 5 true, 21 false before, 3 true, 7 false after (30%): a function the page defines itself is the reader's code and is not judged (pmndrs/jotai's tutorial that rebuilds `atom`, fixture `example-too-many-arguments-jotai-tutorial`), which also drops 2 true findings (a snippet calling its own function wrongly: TanStack/router, react-router).
- Checks: code examples

Reported on:

```text
g.query("MATCH (n) RETURN n", {}, 30)
```

Message: `Graph.query` takes at most 2 positional arguments; the example passes 3.

## example-missing-argument

A docs code example leaves out a required argument. The example fails when copied: a TypeError in Python, a type or compile error in TypeScript and Go.

- Default severity: **info** (**error** when opted in)
- Maturity: **beta**: reported at **info**, lower confidence, until `[rules] "example-missing-argument" = "error"` opts it in. True on flask and pmndrs/jotai (`useFocusAtom(anAtom)` without `keyFn`, a hook the page defines, no longer judged in 0.8.0); the zero-argument calls of API listings are guarded (zod). Drift Hall: 21 true, 856 false (2%). After the 0.8.0 guards, on the 61 hall repositories other than crewAI and haystack: 9 true, 855 false before, 5 true, 37 false after (12%): overloads that disagree (instructor 456), arity from a declared function type (`export const f: F = (a, b) => …`, TanStack/router 315), functions the page defines (vitejs/vite's preset shadowed by an import, fixture `example-missing-argument-vite-shadowed-by-import`).
- Checks: code examples

Reported on:

```text
UserList.as_view()
```

Message: `View.as_view` requires `name`.

## example-missing-import

- Default severity: **info** (**error** when opted in)
- Maturity: **beta**: reported at **info**, lower confidence, until `[rules] "example-missing-import" = "error"` opts it in. - Checks: code examples

Reported on:


Message: `miniclient` has no `connect`.
